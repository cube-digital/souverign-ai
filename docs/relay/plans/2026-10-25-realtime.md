# Realtime Experience Plan

**Goal:** agent turns on the local 4-bit 9B feel live. The first visible status comes at once, a draft streams early, tool steps show as they happen, and voice answers start speaking quickly. Every speed change is measured by one repeatable harness and kept only when it is faster and tool use stays as good as before.
**Spec:** owner request of 2026-10-25 ("don't forget streaming and the realtime experience, even with the 4-bit model"), `docs/superpowers/specs/2026-10-24-agent-teammates-design.md` (👀 + live status within 1 s, "queued, N ahead", receipts), `docs/superpowers/specs/2026-10-24-sovereign-agents-demo-design.md` (voice-to-voice ≤ 2 s on `fast`), `docs/relay/plans/2026-10-24-realtime-agents.md` (signals, streaming drafts), `docs/relay/plans/2026-10-25-voice-meetings.md` (voice turn, `Speaker`, `meta.latency`, T14 voice smoke).
**Runs after:** voice + meetings is merged into the work branch, because this plan edits the voice-merged `services/bridge/src/agents/host.ts` and `services/bridge/src/voice/*`. It can run before or after the connectors plan (see Overlaps).
**Architecture:** the bridge's loopback LLM proxy (`services/bridge/src/llm-proxy.ts`) sees every model round of every Hermes gateway. It becomes the place that measures each round (time to first token, tokens, tool names, prompt sizes) and that applies the per-round policy (thinking off/on/budget, first-round `tool_choice`) from one config file, `config/realtime.yaml`. The agent host adds per-turn marks (first signal, first tool, first draft, reply), and both feed an in-memory perf store. The store is readable at a loopback-only `GET /internal/perf/turns`. A harness in `e2e/perf/` drives fixed prompts per roster agent from real Node devices, joins what the client saw with what the bridge measured, and writes one JSON + one Markdown file per run. Knobs ship with defaults that reproduce today's behaviour. The baseline is measured first, then one live tuning task flips each knob in turn and keeps a change only when the harness shows a gain and both quality gates pass.

## Facts verified while planning (2026-10-25)

- **vllm-mlx 0.4.1** (uv tool; mlx 0.32.4, mlx-lm 0.32.2). Every flag named in this plan appears in `vllm-mlx serve --help` on this Mac. The request fields `chat_template_kwargs`, `enable_thinking` and `thinking_token_budget` (int > 0) exist in `vllm_mlx/api/models.py` `ChatCompletionRequest`, and `server.py` applies them per request.
- **`reasoning_effort` has no effect on Qwen in vllm-mlx 0.4.1.** The only place it is read is the harmony (gpt-oss) renderer and a `chat_template_kwargs.reasoning_effort` path in `engine/simple.py`. So Hermes' `agent.reasoning_effort: low` (in `infra/hermes/config.template.yaml`) most likely leaves the 9B thinking without a limit in every round. T5 confirms this with `reasoningChars` per round.
- **The 9/9 Ops benchmark** (`.handoff/bench/quant_bench.py`, git-excluded) talks to vllm-mlx directly, with `chat_template_kwargs: {enable_thinking: false}`, `tool_choice: "auto"` and temperature 0. That took **6–8 s per question with 2–3 tool calls**, while the same questions through Hermes take **45–62 s**. Most of that gap is what this plan goes after.
- **There is no prefix cache, so every round prefills the whole prompt again** (system prompt + tool schemas + chat context + earlier tool results). Each removed round and each removed prompt token saves time on every round.
- **There is no MTP head in the installed weights.** `mlx-community/Qwen3.5-9B-4bit` declares `mtp_num_hidden_layers: 1`, but its `model.safetensors.index.json` has no `.mtp.` tensors. With `--enable-mtp`, vllm-mlx would log `[MTP] --enable-mtp is set but model has no MTP head` and switch MTP off. A snapshot with MTP weights would be a model download plus a re-benchmark, which is a human decision.
- `--continuous-batching` is documented as "slower for single user". `--stream-interval` defaults to 1 (already smooth). `--chunked-prefill-tokens` defaults to 0 (off). `--prefill-step-size` defaults to 2048.
- Today: `SA_LLM_CONCURRENCY` defaults to 2 (`turn-queue.ts`), `WRITING_GAP_MS = 400`, `CONTEXT_MESSAGES = 20`, `THREAD_REPLIES = 10`, `MIN_GAP_MS = 3000` (`host.ts`), and Hermes runs with `max_turns: 8` and tool search off. The voice `SentenceSplitter` cuts at `[.!?…]` + whitespace with a minimum of 12 chars, and `Speaker` runs TTS one sentence after another.
- `espeak-ng`, `ffmpeg` and `livekit-server` are installed on this Mac.

## Decisions

- **Measure first, change second.** Every knob below is a value in `config/realtime.yaml` (or `serve_flags` in `config/models.yaml`). The values that land with T1/T6 reproduce today's behaviour exactly, so the T5 baseline measures the current system. Only T10 changes values, one knob at a time.
- **Quality gates (both must hold for every kept change):**
  - **ops9**: the three benchmark questions × 3, asked of Ops in Ana's DM through the full stack. The questions are "Is anything about to go wrong in the cluster in the next few hours?" → must contain `node-3`; "Is the database sync working fine, and where is the raft leader now?" → `db-2` and `node-1`; "When was janosch last connected?" → `7.4.0-rc2`. The check is case-insensitive and needs `meta.tools.length ≥ 1`. **9/9 required.**
  - **vague5**: "how are things?" asked of Ops 5 times (the roster-smoke prompt, in a DM so no tag is needed), each with `meta.tools.length ≥ 1`. **5/5 required.** This is stricter than roster-smoke's 4/5.
- **Keep rule (T10).** A change is kept when, on the `quick` set with the same repeats, p50 `total_ms` improves by ≥ 10% (or the knob's own target metric does, see Budgets), p95 gets no worse than +10%, both gates pass, and the swap-used delta between the A and B runs is ≤ 2 GiB. Otherwise rerun once; if it still fails, revert the knob.
- **Thinking policy per round.** The proxy knows the turn kind (`chat`, `voice`, `proactive`; set by the host per agent, like `setForceFirstTool`) and whether the round comes after tool results. For each pair it applies `on` (unchanged), `off` (`chat_template_kwargs.enable_thinking = false`, the same mechanism the 9/9 bench used) or a budget N (`thinking_token_budget: N`, 64–8192).
- **First-round `tool_choice`** stays `required` for tool-bearing templates (bug 4), and can be set per turn kind. `auto` is only a candidate for kinds where the gates still pass.
- **Perf data is ids, timings, counts and sizes only.** The perf store, the proxy log and the harness results never hold message text, drafts, tool arguments or tool results. The harness keeps answers in memory only to score the gates.
- **The perf readout is loopback only.** `GET /internal/perf/turns` uses the same guard as the LLM proxy: loopback socket, loopback Host, no `x-forwarded-*`. Through `make share` it answers 403.
- **The voice "spoken ack"** (a short phrase spoken when no answer audio exists after `ack_after_ms`) is built but **off** (`ack_phrase: ""`), because turning it on is the human's call. When it is on, `meta.latency.first_audio_ms` still means the first *answer* audio, and the ack is reported separately, so the number stays honest.
- **Never:** `--enable-prefix-cache`, `--warm-prompts` (it fills the prefix cache), `--ssd-cache-dir`, `--prefix-cache-size`, `--mtp-optimistic` (5–10% wrong tokens break tool JSON) or `--specprefill` (needs a draft model, and the help text warns of quality loss). `sa-models serve-flags` refuses them (T6).

## Budgets (what each knob must buy to be kept)

| knob | where | expected effect | keep if (quick set, vs current best) |
|---|---|---|---|
| thinking off, `chat.first_round` | realtime.yaml | the forced tool round stops reasoning; first tool ≈ prefill + one tool call | `first_tool_ms` p50 −30% and gates pass |
| thinking off or 256, `chat.after_tools` | realtime.yaml | the follow-up and final rounds stop reasoning | `total_ms` p50 −20% and gates pass |
| thinking off, `voice.*` | realtime.yaml | voice answers start sooner | voice `first_audio_ms` p50 −30% |
| `queue.llm_concurrency` 1 | realtime.yaml | two users: the first answer twice as fast, same last answer | pair scenario: mean `total_ms` −15%, max no worse than +10% |
| drop `--continuous-batching` (only with concurrency 1) | models.yaml serve_flags | single-stream decode speed | solo `total_ms` p50 −5% |
| `--chunked-prefill-tokens 1024` (only with concurrency 2) | serve_flags | a running draft keeps streaming during the other turn's prefill | pair: p95 gap between draft signals −30% |
| `--prefill-step-size 4096` | serve_flags | faster prefill of long prompts | round-1 `firstTokenMs` p50 −10% |
| `context.messages` 20 → 12, `voice_messages` → 8 | realtime.yaml | smaller prompt every round | `total_ms` p50 −5% and gates pass |
| `writing_gap_ms` 400 → 200 | realtime.yaml | smoother drafts | draft signal gap p50 ≤ 250 ms, total unchanged ±5% |
| Hermes prompt diet (T9) | hermes config/SOUL | fewer prompt tokens per round | round-1 `promptTokens` −15% and `total_ms` p50 −5% |
| `voice.early_first_chunk` | realtime.yaml | the first clause goes to TTS before the sentence ends | voice `first_audio_ms` p50 −300 ms |

## Review Focus

- The proxy forwards the gateway's stream byte for byte, except for the one usage-only chunk it asked for itself. No SSE event is held back until the end: the observer must emit each event as soon as its boundary arrives, whether the stream uses `\n\n` or `\r\n\r\n`.
- With default config, the upstream body differs from today's only by `stream_options.include_usage` on streams the gateway did not ask usage for. `tool_choice: "required"` is still applied exactly when it is today.
- Perf entries never carry text, are capped (500 finished turns, 30 rounds per turn, 20 tool names per round) and leak no memory for turns that never end (15-minute sweep).
- Rounds are attributed to the right turn. That holds because one turn per agent runs at a time (TurnQueue `runningAgents`) and `perfRun` is set when the turn is dequeued. Proactive and `complete()` turns without `perfBegin` are ignored, never misattributed.
- The ack never counts as answer audio, and a stopped voice turn speaks no ack.
- T10 kept nothing that failed a gate. Each kept change has its A/B numbers in `docs/perf/2026-10-25-realtime.md`.

## Human decisions (asked in the hand-over, not blocking the run)

1. **Spoken ack in voice turns** ("One moment, checking the cluster." style, `voice.ack_phrase`). Off by default. On makes the ≤ 2 s target reachable for tool turns, but only as an ack.
2. **The < 2 s voice-to-voice target for tool-bearing agents** (Ops) cannot be met by an answer that needs a tool round on this model. Accept that the target applies to conversational turns (and the ack), or move voice to a no-tool fast path for those agents.
3. **An MTP-capable snapshot** of the 9B (download + benchmark again) for speculative decoding.
4. Close other apps before live runs. The machine was at 14–19 GiB swap, and the harness flags A/B pairs whose swap differs by more than 2 GiB.

`services/bridge/src/realtime/config.ts`:

```ts
import { readFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";
import { parse } from "yaml";

export type Thinking = "on" | "off" | number;
export type TurnKind = "chat" | "voice" | "proactive";
export type ToolChoice = "required" | "auto";

export type RealtimeConfig = {
  thinking: Record<TurnKind, { first_round: Thinking; after_tools: Thinking }>;
  first_round_tool_choice: Record<TurnKind, ToolChoice>;
  context: { messages: number; voice_messages: number; thread_replies: number };
  writing_gap_ms: number;
  queue: { llm_concurrency: number };
  voice: {
    early_first_chunk: boolean;
    first_chunk_min_chars: number;
    ack_phrase: string;
    ack_after_ms: number;
  };
};

const KINDS: TurnKind[] = ["chat", "voice", "proactive"];

export const REALTIME_DEFAULTS: RealtimeConfig = {
  thinking: {
    chat: { first_round: "on", after_tools: "on" },
    voice: { first_round: "on", after_tools: "on" },
    proactive: { first_round: "on", after_tools: "on" },
  },
  first_round_tool_choice: { chat: "required", voice: "required", proactive: "required" },
  context: { messages: 20, voice_messages: 20, thread_replies: 10 },
  writing_gap_ms: 400,
  queue: { llm_concurrency: 2 },
  voice: { early_first_chunk: false, first_chunk_min_chars: 24, ack_phrase: "", ack_after_ms: 1500 },
};

const ROOT = join(dirname(fileURLToPath(import.meta.url)), "..", "..", "..", "..");

type Raw = Record<string, unknown>;
const obj = (v: unknown): Raw =>
  v && typeof v === "object" && !Array.isArray(v) ? (v as Raw) : {};
const int = (v: unknown, min: number, max: number, fallback: number): number =>
  typeof v === "number" && Number.isInteger(v) && v >= min && v <= max ? v : fallback;

/** "on" | "off" | an integer token budget in [64, 8192]; anything else → fallback. */
export function parseThinking(v: unknown, fallback: Thinking): Thinking {
  if (v === "on" || v === true) return "on";
  if (v === "off" || v === false) return "off";
  const n = typeof v === "string" && /^\d+$/.test(v) ? Number(v) : v;
  if (typeof n === "number" && Number.isInteger(n) && n >= 64 && n <= 8192) return n;
  return fallback;
}

export function normalizeRealtime(raw: unknown): RealtimeConfig {
  const r = obj(raw);
  const d = REALTIME_DEFAULTS;
  const thinking = {} as RealtimeConfig["thinking"];
  const choice = {} as RealtimeConfig["first_round_tool_choice"];
  for (const k of KINDS) {
    const t = obj(obj(r.thinking)[k]);
    thinking[k] = {
      first_round: parseThinking(t.first_round, d.thinking[k].first_round),
      after_tools: parseThinking(t.after_tools, d.thinking[k].after_tools),
    };
    const c = obj(r.first_round_tool_choice)[k];
    choice[k] = c === "auto" || c === "required" ? c : d.first_round_tool_choice[k];
  }
  const ctx = obj(r.context);
  const v = obj(r.voice);
  return {
    thinking,
    first_round_tool_choice: choice,
    context: {
      messages: int(ctx.messages, 1, 50, d.context.messages),
      voice_messages: int(ctx.voice_messages, 1, 50, d.context.voice_messages),
      thread_replies: int(ctx.thread_replies, 0, 50, d.context.thread_replies),
    },
    writing_gap_ms: int(r.writing_gap_ms, 50, 2000, d.writing_gap_ms),
    queue: { llm_concurrency: int(obj(r.queue).llm_concurrency, 1, 8, d.queue.llm_concurrency) },
    voice: {
      early_first_chunk:
        typeof v.early_first_chunk === "boolean" ? v.early_first_chunk : d.voice.early_first_chunk,
      first_chunk_min_chars: int(v.first_chunk_min_chars, 8, 200, d.voice.first_chunk_min_chars),
      ack_phrase: typeof v.ack_phrase === "string" ? v.ack_phrase.slice(0, 80) : d.voice.ack_phrase,
      ack_after_ms: int(v.ack_after_ms, 300, 10_000, d.voice.ack_after_ms),
    },
  };
}

let cached: RealtimeConfig | null = null;

/** config/realtime.yaml (or SA_REALTIME_CONFIG), read once. A missing or broken file → defaults. */
export function realtimeConfig(): RealtimeConfig {
  if (cached) return cached;
  const file = process.env.SA_REALTIME_CONFIG || join(ROOT, "config", "realtime.yaml");
  let raw: unknown = {};
  try {
    raw = parse(readFileSync(file, "utf8"));
  } catch (e) {
    console.warn(
      JSON.stringify({
        level: "warn",
        msg: "realtime config unreadable, using defaults",
        error: (e as Error).name,
      }),
    );
  }
  cached = normalizeRealtime(raw);
  return cached;
}

export function setRealtimeConfigForTests(c: RealtimeConfig | null): void {
  cached = c;
}
```

`services/bridge/src/realtime/policy.ts`:

```ts
import type { RealtimeConfig, Thinking, TurnKind } from "./config.js";

export type RoundPlan = { thinking: Thinking; forced: boolean };

/** What the proxy does to one model round. `forcible` = today's bug-4 rule holds for this
 * request (tool-bearing template, force flag on, tools present, tool_choice unset or auto). */
export function planRound(
  cfg: RealtimeConfig,
  r: { kind: TurnKind; afterTools: boolean; forcible: boolean },
): RoundPlan {
  const t = cfg.thinking[r.kind];
  return {
    thinking: r.afterTools ? t.after_tools : t.first_round,
    forced: r.forcible && !r.afterTools && cfg.first_round_tool_choice[r.kind] === "required",
  };
}

/** Request fields verified in vllm-mlx 0.4.1 (`api/models.py` ChatCompletionRequest):
 * `chat_template_kwargs.enable_thinking` and `thinking_token_budget` (int > 0). */
export function applyThinking<T extends Record<string, unknown>>(body: T, t: Thinking): T {
  if (t === "on") return body;
  if (t === "off") {
    const prev = body.chat_template_kwargs;
    const kw =
      prev && typeof prev === "object" && !Array.isArray(prev)
        ? (prev as Record<string, unknown>)
        : {};
    return { ...body, chat_template_kwargs: { ...kw, enable_thinking: false } };
  }
  return { ...body, thinking_token_budget: t };
}
```

`services/bridge/src/realtime/perf.ts`:

```ts
import type { Thinking, TurnKind } from "./config.js";

export type PerfMark =
  | "first_signal"
  | "dequeued"
  | "context_ready"
  | "first_round"
  | "first_tool"
  | "first_draft"
  | "reply_sent";

export type RoundSizes = {
  system: number;
  tools: number;
  messages: number;
  toolCount: number;
  messageCount: number;
};

export type RoundPerf = {
  n: number;
  /** ms after the turn started */
  at: number;
  ms: number;
  firstTokenMs: number | null;
  firstContentMs: number | null;
  promptTokens: number | null;
  completionTokens: number | null;
  reasoningChars: number;
  contentChars: number;
  toolCalls: string[];
  forced: boolean;
  thinking: Thinking;
  status: number;
  stream: boolean;
  sizes: RoundSizes;
  /** what the gateway asked for: field names, plus three scalar values */
  sent: { keys: string[]; reasoning_effort?: string; max_tokens?: number; tool_choice?: string };
};

export type TurnPerf = {
  turnId: string;
  agentId: string;
  template: string;
  kind: TurnKind;
  trigger: string;
  startedAt: number;
  marks: Partial<Record<PerfMark, number>>;
  rounds: RoundPerf[];
  contextChars: number | null;
  outcome: string | null;
  doneMs: number | null;
  voice: { sttMs: number; firstAudioMs: number | null; ackMs: number | null; totalMs: number } | null;
};

const MAX_FINISHED = 500;
const MAX_ROUNDS = 30;
const STALE_MS = 15 * 60_000;
const open = new Map<string, TurnPerf>();
const running = new Map<string, string>(); // agentId → turnId
const finished: TurnPerf[] = [];

export function perfBegin(t: {
  turnId: string;
  agentId: string;
  template: string;
  kind: TurnKind;
  trigger: string;
  startedAt: number;
}): void {
  const now = Date.now();
  for (const [id, p] of open) {
    if (now - p.startedAt <= STALE_MS) continue;
    open.delete(id);
    if (running.get(p.agentId) === id) running.delete(p.agentId);
  }
  open.set(t.turnId, {
    ...t,
    marks: {},
    rounds: [],
    contextChars: null,
    outcome: null,
    doneMs: null,
    voice: null,
  });
}

/** The turn left the queue: model rounds of its agent belong to it from now on. */
export function perfRun(turnId: string, at = Date.now()): void {
  const p = open.get(turnId);
  if (!p) return;
  running.set(p.agentId, turnId);
  perfMark(turnId, "dequeued", at);
}

/** First value wins. */
export function perfMark(turnId: string, mark: PerfMark, at = Date.now()): void {
  const p = open.get(turnId);
  if (p && p.marks[mark] === undefined) p.marks[mark] = Math.max(0, at - p.startedAt);
}

export function perfSet(turnId: string, patch: Partial<Pick<TurnPerf, "contextChars" | "voice">>): void {
  const p = open.get(turnId);
  if (p) Object.assign(p, patch);
}

/** Called by the LLM proxy when a round of this agent ends. */
export function perfRound(
  agentId: string,
  round: Omit<RoundPerf, "n" | "at"> & { startedAt: number },
): void {
  const id = running.get(agentId);
  const p = id ? open.get(id) : undefined;
  if (!p || p.rounds.length >= MAX_ROUNDS) return;
  const { startedAt, ...rest } = round;
  const at = Math.max(0, startedAt - p.startedAt);
  if (p.marks.first_round === undefined) p.marks.first_round = at;
  p.rounds.push({ ...rest, toolCalls: rest.toolCalls.slice(0, 20), n: p.rounds.length + 1, at });
}

export function perfEnd(turnId: string, outcome: string, at = Date.now()): void {
  const p = open.get(turnId);
  if (!p) return;
  open.delete(turnId);
  if (running.get(p.agentId) === turnId) running.delete(p.agentId);
  p.outcome = outcome;
  p.doneMs = Math.max(0, at - p.startedAt);
  finished.push(p);
  if (finished.length > MAX_FINISHED) finished.splice(0, finished.length - MAX_FINISHED);
}

/** Finished turns that started at or after `since` (ms since epoch), oldest first. */
export function perfTurns(since: number): TurnPerf[] {
  return finished.filter((t) => t.startedAt >= since);
}

export function resetPerfForTests(): void {
  open.clear();
  running.clear();
  finished.length = 0;
}
```

```ts
export type RoundObservation = {
  firstTokenAt: number | null;

  reasoningChars: 0,
  contentChars: 0,
  toolCalls: [],
  promptTokens: null,

type Msg = {
  content?: unknown;
  reasoning_content?: unknown;
  reasoning?: unknown;
  tool_calls?: unknown;
};

function note(obs: RoundObservation, d: Msg | undefined, now: number): void {
  if (!d) return;
  const r = typeof d.reasoning_content === "string" ? d.reasoning_content : d.reasoning;
  const c = d.content;
  const calls = Array.isArray(d.tool_calls) ? (d.tool_calls as { function?: { name?: unknown } }[]) : [];
  const hasR = typeof r === "string" && r.length > 0;
  const hasC = typeof c === "string" && c.length > 0;
  if ((hasR || hasC || calls.length > 0) && obs.firstTokenAt === null) obs.firstTokenAt = now;
  if (hasR) obs.reasoningChars += (r as string).length;
  if (hasC) {
    obs.contentChars += (c as string).length;
    if (obs.firstContentAt === null) obs.firstContentAt = now;
  }
  for (const tc of calls) {
    const name = tc?.function?.name;
    if (typeof name === "string" && name && obs.toolCalls.length < 20) obs.toolCalls.push(name.slice(0, 64));
  }
}

function usage(obs: RoundObservation, u: unknown): void {
  if (!u || typeof u !== "object") return;
  const { prompt_tokens: p, completion_tokens: c } = u as Record<string, unknown>;
  if (typeof p === "number") obs.promptTokens = p;
  if (typeof c === "number") obs.completionTokens = c;
}

/** Non-streaming completion. */
export function observeJson(obs: RoundObservation, body: unknown, now = Date.now()): void {
  const j = body as { choices?: { message?: Msg }[]; usage?: unknown } | null;
  for (const ch of j?.choices ?? []) note(obs, ch?.message, now);
  usage(obs, j?.usage);
}

function boundary(buf: string): [number, number] | null {
  const a = buf.indexOf("\n\n");
  const b = buf.indexOf("\r\n\r\n");
  if (a < 0 && b < 0) return null;
  if (b >= 0 && (a < 0 || b < a)) return [b, 4];
  return [a, 2];
}

/** Passes the SSE stream through event by event, unchanged, while noting timings, sizes and tool
 * names. With `stripUsageOnly`, the usage-only event the proxy asked for (`choices: []` plus
 * `usage`) is noted and dropped, so the gateway sees the stream it requested. */
export function sseObserver(
  obs: RoundObservation,
  opts: { stripUsageOnly: boolean; now?: () => number },
): TransformStream<Uint8Array, Uint8Array> {
  const now = opts.now ?? Date.now;
  const dec = new TextDecoder();
  const enc = new TextEncoder();
  let buf = "";
  /** Returns true when the event must be dropped. */
  const inspect = (event: string): boolean => {
    let drop = false;
    for (const line of event.split(/\r?\n/)) {
      if (!line.startsWith("data:")) continue;
      const data = line.slice(5).trim();
      if (!data || data === "[DONE]") continue;
      let j: { choices?: { delta?: Msg }[]; usage?: unknown } | null = null;
      try {
        j = JSON.parse(data);
      } catch {
        continue;
      }
      if (j?.usage) usage(obs, j.usage);
      if (Array.isArray(j?.choices)) {
        if (j.choices.length === 0 && j.usage && opts.stripUsageOnly) drop = true;
        for (const ch of j.choices) note(obs, ch?.delta, now());
      }
    }
    return drop;
  };
  return new TransformStream({
    transform(chunk, ctl) {
      buf += dec.decode(chunk, { stream: true });
      for (;;) {
        const b = boundary(buf);
        if (!b) break;
        const raw = buf.slice(0, b[0] + b[1]);
        buf = buf.slice(b[0] + b[1]);
        if (!inspect(raw.slice(0, b[0]))) ctl.enqueue(enc.encode(raw));
      }
    },
    flush(ctl) {
      buf += dec.decode();
      if (buf && !inspect(buf)) ctl.enqueue(enc.encode(buf));
    },
  });
}
```
